# 后端服务访问失败 - 问题排查指南

## 问题现象
访问 `http://localhost:8080/api` 失败

## 重要说明

**`/api` 只是上下文路径，不是实际的接口地址！**

正确的访问方式：
- ❌ 错误：`http://localhost:8080/api`
- ✅ 正确：`http://localhost:8080/api/subject/dates`
- ✅ 正确：`http://localhost:8080/api/auth/login`
- ✅ 正确：`http://localhost:8080/api/health/check` (健康检查接口)

## 排查步骤

### 1. 检查服务是否启动

#### 方法1：检查Java进程
```powershell
Get-Process | Where-Object {$_.ProcessName -like "*java*"}
```

#### 方法2：检查端口监听
```powershell
netstat -ano | Select-String ":8080"
```

如果看到 `LISTENING` 状态，说明服务已启动。

### 2. 查看启动日志

启动服务时，查看控制台输出，确认：
- ✅ 看到 "Started StockApplication" 表示启动成功
- ❌ 看到数据库连接错误，需要检查数据库配置
- ❌ 看到端口占用错误，需要更换端口或关闭占用进程

### 3. 测试服务是否正常

#### 测试健康检查接口（最简单）
在浏览器访问：
```
http://localhost:8080/api/health/check
```

预期返回：
```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "status": "ok",
    "message": "服务运行正常",
    "timestamp": "1234567890"
  }
}
```

#### 测试主题日期接口
```
http://localhost:8080/api/subject/dates
```

### 4. 常见问题及解决方案

#### 问题1：数据库连接失败

**错误信息**：
```
Communications link failure
或
Access denied for user
```

**解决方案**：
1. 检查 `application.yml` 中的数据库配置
2. 确认数据库服务是否运行
3. 检查网络连接（如果是远程数据库）
4. 验证用户名和密码是否正确

#### 问题2：端口被占用

**错误信息**：
```
Port 8080 is already in use
```

**解决方案**：
1. 查找占用端口的进程：
   ```powershell
   netstat -ano | Select-String ":8080"
   ```
2. 关闭占用进程或修改 `application.yml` 中的端口号

#### 问题3：表不存在

**错误信息**：
```
Table 'cfdb.subject_message' doesn't exist
```

**解决方案**：
1. 执行建表语句：`backend/src/main/resources/db/schema.sql`
2. 确认数据库名称是否正确

#### 问题4：Mapper文件找不到

**错误信息**：
```
Could not find resource mapper/xxxMapper.xml
```

**解决方案**：
1. 检查 `src/main/resources/mapper/` 目录下是否有对应的XML文件
2. 检查 `application.yml` 中的 `mapper-locations` 配置

### 5. 重新启动服务

如果服务启动失败，按以下步骤操作：

1. **停止当前服务**
   - 如果在前台运行，按 `Ctrl+C`
   - 如果在后台运行，找到Java进程并结束

2. **清理并重新编译**
   ```powershell
   cd backend
   mvn clean compile
   ```

3. **重新启动**
   ```powershell
   mvn spring-boot:run
   ```
   或使用启动脚本：
   ```powershell
   .\start.bat
   ```

### 6. 验证服务正常工作的步骤

1. ✅ 服务启动成功（看到 "Started StockApplication"）
2. ✅ 端口8080处于LISTENING状态
3. ✅ 访问 `http://localhost:8080/api/health/check` 返回JSON响应
4. ✅ 访问 `http://localhost:8080/api/subject/dates` 返回数据（可能需要数据库中有数据）
